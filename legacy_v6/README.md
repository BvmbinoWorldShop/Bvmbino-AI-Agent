## 🚀 Deployment (10 Minutes)

### 1. Prerequisites
- [Vercel CLI](https://vercel.com/download) installed.
- API Keys for at least one provider (Groq or Gemini recommended).

### 2. Strategic Sync
Clone this repo and run:
```bash
vercel --prod
```

### 3. Environment Variables
Add these to your **Vercel Project Settings** (Ensure the "Production" box is checked):
- `GROQ_KEY`: Your Groq API key (for speed).
- `GEMINI_KEY`: Your Google AI key (for vision & search).
- `JWT_SECRET`: A custom string to secure your session.
- `OPENROUTER_KEY`: (Optional) For specialized model access.
